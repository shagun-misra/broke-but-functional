# Broke But Functional — Survive the Month
> High-Impact Financial Scenario Simulation Engine for Gen-Z & Students

An interactive personal finance simulator that tests survival across a 30-day period with a hard starting budget constraint of **₹10,000**. Built for the **PROMPT RUN 2026** hackathon.
